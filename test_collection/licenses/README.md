# License Information for Test Collection

This directory contains the license/attribution information for all audio files in the test_collection.

## Source
All audio files and their corresponding license/attribution information are sourced from the **Library of Congress National Jukebox Classical Collection** via the [Citizen DJ project](https://citizen-dj.labs.loc.gov/loc-jukebox-classical/use/).

## License Status
All recordings in this collection are in the **public domain** under the Music Modernization Act. As stated by the Library of Congress:

> "Under the Music Modernization Act, this item entered public domain on January 1, 2022, when all recordings published prior to 1923 entered the public domain and became free to use and reuse."

## File Structure
Each audio file in the test_collection has a corresponding `.txt` file in this directory with the same base name, containing:
- Title and URL of the original recording
- Contributors (composer, vocalist, conductor, etc.)
- Rights and access information
- Public domain status confirmation
- Suggested credit/attribution

## File Mapping
Each audio file in the test_collection (MP3, FLAC, OGG, M4A, WAV, AIFF) has a corresponding license file with the same base name:
- `example_jukebox-12345.mp3` → `example_jukebox-12345.txt`
- `example_jukebox-12345.flac` → `example_jukebox-12345.txt`
